# Connected Components

**Author:** 37c243f2  
**Difficulty:** Easy

## Description
Finds all connected components in an undirected graph. Each component includes its nodes, size, and registered subgraph ID.

## Parameters
No additional parameters are required.

## Output
Returns:
- The number of connected components.
- Each component's node list and size.
- A subgraph ID for each component.
- A summary identifying the largest component.

## Errors
Returns an error if:
- The graph ID is invalid or the graph cannot be loaded.
- The graph is directed.
- Unexpected parameters are provided.
